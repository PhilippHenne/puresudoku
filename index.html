Install on Android (Zero Build Errors!)

Why you got a 404 & React errors earlier (Now Fixed!)

Previously, the app was a .jsx React file, which browsers and GitHub Pages cannot open directly without a Node/Vite compiler. This new version is 100% pure HTML & Vanilla JavaScript inside a single index.html file.

Method 1 (Easiest)

GitHub Pages + Android "Install App"

  1. Click the Download Standalone index.html File button above (or copy the code from the editor and save it on your computer as index.html — make sure it is lowercase!).
  2. Go to GitHub, create a new public repository (e.g. sudoku), click Add file → Upload files, and drop index.html right in the main root folder. Commit the changes.
  3. In your GitHub repo, click Settings → Pages (on the left sidebar). Under Branch, select main (and /root) and click Save.
  4. Wait 60 seconds, then open https://YOUR-USERNAME.github.io/sudoku/ in Chrome on your Android phone.
  5. Tap Chrome's menu (⋮) → Add to Home screen → Install App. You now have a full-screen offline Android app!
Method 2 (No Coding)

Get a Real .apk from Your GitHub Pages URL

Once your GitHub Pages link is live, if you still prefer a real sideloadable .apk file without installing Android Studio:

  1. Go to PWABuilder.com and paste your GitHub Pages URL.
  2. Click Package for stores → Android → Download Package.
  3. Unzip the download and copy the included .apk file to your phone to sideload!
Method 3 (Local CLI)

Build app-debug.apk Locally (No React)

Because this file needs zero bundling, you can skip React/Vite completely. Put your downloaded index.html into a folder and run: 

mkdir puresudoku && cd puresudoku
mkdir www
# Move your downloaded index.html into the www/ folder:
# puresudoku/www/index.html

npm init -y
npm install @capacitor/core @capacitor/cli @capacitor/android
npx cap init PureSudoku com.puresudoku.app --web-dir www
npx cap add android
npx cap copy

# Build the sideloadable APK:
cd android && ./gradlew assembleDebug

Your APK will be ready at: android/app/build/outputs/apk/debug/app-debug.apk
